# v0.24.2 LongMemEval P0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 LongMemEval 全量 500 条前的 P0-1 至 P0-7、P1-1 窄版和 P1-4，并发布 v0.24.2。

**Architecture:** 生产路径只修改时间纯函数、preference finalization 与 compact extractor prompt；评测专属的逐 turn ingest、reader、聚合和 raw assistant fallback 留在 LongMemEval adapter/reader context。现有 SQLite event schema 足够承载 speaker/session/span，不新增 migration 或依赖。

**Tech Stack:** Python 3.11、SQLite/FTS5、FastAPI 项目工具链、unittest/pytest、uv。

## Global Constraints

- 不修改评测数据集。
- 不调整生产阈值 0.82/0.92/0.95。
- 不新增全量 turn-vector schema。
- 本地不运行 pytest；GitHub Actions 运行全量测试。
- 最终版本为 v0.24.2，并同步 CHANGELOG/README/HANDOFF/architecture 等版本引用。
