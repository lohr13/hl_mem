**Goal:** Ship the five approved v0.29.0 temporal-correctness items in the locked order A1, B generation/reopen, A2, A3, and F, with production-history replay gates and no issue-platform or dynamic-negotiation expansion.

**Architecture:** Persist one orthogonal epistemic gate (`unknown`, `observation`, `inference`) whose migration default is observable but inert. Reuse the existing exclusive-slot conflict group generation machinery after terminal decisions, and add a separate conservative temporal-link classifier for explicit replacements; it may auto-link only uniquely proven updates and sends ambiguous replacement intent to the existing pair conflict pipeline. Keep current-state retrieval unchanged and prove it excludes closed links. Expose static daemon/plugin/wire contract facts through health and doctor without per-request negotiation.

**Tech Stack:** Python 3.11+, FastAPI, Pydantic, SQLite migrations/WAL/FTS5, pytest, black, isort, ruff, mypy.
