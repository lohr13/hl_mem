# Embedding Ablation 结果

文件按实验族命名：`embedding_ablation_*` 为总体消融，`lme_embedding_calibration_*` 为校准，`lme_embedding_sel_*` 为模型选择；运行日志位于 `_logs/`，smoke、canary、语料快照和辅助产物位于 `_archive/`。

代表结果为 `embedding_ablation_v1.json`、`lme_embedding_calibration_v1.json` 及其报告，以及 `lme_embedding_sel_v1_hard6.json`、`lme_embedding_sel_v1_pairs.json` 和最终报告。
